# CoreAI responsive design

Follow existing shell layouts and colocated CSS Modules. Preserve accessible navigation and settings on the affected viewports. Use CoreAI components and documented tokens before adding custom responsive behavior.

For changed layouts, check the requested desktop and narrow viewport behavior, including navigation, overflow and reachable actions. Preserve readable content rather than clipping it to make a screenshot fit. Use the [browser validation guidance](BROWSER-VALIDATION.md) for rendered evidence.

The example does not define additional device targets or team breakpoints. Resolve task-specific target requirements before making consequential layout changes.
