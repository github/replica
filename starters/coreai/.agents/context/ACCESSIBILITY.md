# CoreAI accessibility

Preserve semantic elements, accessible names, keyboard navigation, focus order and visible focus when changing the example. Use the documented accessibility behavior of CoreAI components; do not replace supported primitives with styled raw elements merely for appearance.

For affected interactions, verify keyboard access, labels, focus movement and any changed loading, error or status feedback. Follow [browser validation guidance](BROWSER-VALIDATION.md) and report which checks were actually performed. Automated checks do not establish complete accessibility conformance.

This example declares no product-specific assistive-technology support matrix or certification. Ask for those requirements when the task depends on them; do not claim conformance without evidence.
