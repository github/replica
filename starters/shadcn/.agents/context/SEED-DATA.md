# Shadcn sample data

The dashboard uses the official block's generated sample data in `src/app/dashboard/data.json`. The working Records flow uses fictional projects in `src/data/records.ts`. No data comes from a service.

Keep fixtures local, deterministic and free of private information. Use fictional names and example email addresses. Do not infer customer facts or business commitments from the samples.

Settings are stored under `replica-shadcn-settings` in browser storage. Clearing that entry restores the included defaults; no account or server state changes.
