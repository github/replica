# Shadcn accessibility

Use installed Radix/shadcn primitives for focus behavior, dialogs and the responsive sidebar. Keep visible form labels, meaningful dialog titles and keyboard-operable controls. Preserve link semantics for navigation and expose the current page with `aria-current`.

Search result counts and successful saves use status messages; validation and storage failures use alerts. Do not remove these semantics when adapting the example. Check keyboard navigation, focus return after dialogs and usable form feedback in the browser. The starter is not a claim of conformance to a consuming team's accessibility policy.
